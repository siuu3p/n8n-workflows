# n8n-workflows

Repository to store my n8n workflows.

| Workflow | What it does |
|---|---|
| [Lead Intake Automation](lead-intake-automation/) | Form to cleaned lead, duplicate check, Google Sheets and Notion logging, Gmail auto-reply, and high-priority owner alert |
| [AI Customer Support Agent](ai-customer-support-agent/) | Gmail support inbox to OpenAI agent with a Notion knowledge base, Slack approval for refunds, account deletions and low-confidence answers, and Gmail draft replies |
| [Competitive Pricing Intelligence](competitive-pricing-intelligence/) | Daily scrape of competitor pricing pages, OpenAI plan extraction, Postgres baseline comparison, and Slack and email change alerts |
